# Robot nettoyeur d'escaliers
Le projet consiste à contrôler un robot qui monte les escaliers et qui les nettoie en aspirant la poussière. 
Pour cela, un système à deux robots a été choisi.
Un qui monte les escaliers comportant une plateforme, qui accueille un deuxième robot plus petit qui s'occupe de l'aspiration. 
Le tout est contrôlé avec un interface graphique codée en Python.
