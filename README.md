# Robot nettoyeur d'escaliers
Le projet consiste à contrôler un robot qui monte les escaliers et qui les néttoie en aspirant la poussière. 
Pour cela, un système à deux robots à été choisi.
Un qui monte les escaliers comportant une plateforme, qui accueille un deuxième robot plus petit qui s'occuppe de l'aspiration. 
Le tout est contrôler avec un interface graphique codée en Python.
